所有条目在同一集成分支汇合。条目 1 是为共享网络配置进行的前置重构；后续条目逐步接入账号策略并验证用户行为。单个条目完成不代表整个产品可以发布。严格隔离启用后，尚未接入的具体联网路径先阻断，不能暂时借用全局代理或直连。

## 1. 建立账号网络上下文与统一连接约束

**依赖**：无。

**交付**：为每个账号提供稳定的网络上下文，涵盖绑定、阻断状态和连接配置版本。以兼容适配方式替换底层直接读取全局可变代理的依赖，为后续迁移提供一致入口。

**验收**：

- 两个账号的配置变更互不覆盖，账号身份不依赖当前窗口或列表索引。
- 连接请求携带明确账号上下文；缺少上下文时不能冒用当前账号。
- 配置版本更新后，旧检测结果和旧回调不能重新放行连接。
- 原有网络行为的针对性回归通过；此阶段不宣称已实现全流量隔离。

## 2. 登录前绑定代理、旧账号迁移与失效阻断

**依赖**：1。

**交付**：用户可在登录前及现有账号的基础设置中绑定 SOCKS5 或 MTProto。配置和绑定可保存恢复，旧账号保留数据且默认未绑定阻断。

**验收**：

- 两种协议分别完成绑定、必要检测、认证和后台消息连接；不使用本机 DNS 解析代理入口。
- 未绑定、检测未通过和代理失效时不发送账号业务请求；修复绑定后恢复对应账号。
- 旧代理只导入代理库，迁移不自动给账号绑定；重复启动不覆盖已有绑定。
- 编辑或替换代理先终止旧连接；共享代理只影响明确绑定它的账号。
- 严格模式下未接入账号策略的功能明确阻断，不继续使用旧全局出口。
- 基础设置提供真实状态和错误提示，不依赖最终管理页面才能完成验证。

## 3. 文件、网页文件、直播分片和辅助请求隔离

**依赖**：2。

**交付**：账号的上传下载、网页文件、直播分片、必要配置和辅助请求使用绑定策略；保留可通过 MTProto 完成的路径。

**验收**：

- 常规文件、网页文件和直播分片通过对应账号的 SOCKS5/MTProto 连接，不能按代理类型一律禁用。
- HTTP 下载、重定向、域名解析、特殊配置和时间同步均核查实际出口；不能隔离的具体路径明确阻断。
- 并发传输不串用另一账号的网络池或认证状态。
- 代理失效和绑定变更期间，已排队及进行中的传输均受约束。

## 4. 通话信令与实时媒体分别接入账号策略

**依赖**：2。

**交付**：通话发起、接听和群通话按照账号的网络能力执行；分别判断信令和实时媒体能否满足隔离。

**验收**：

- 双向通话和群通话覆盖信令、WebRTC、P2P、STUN/TURN 及屏幕共享等实际使用路径。
- 信令可用不能让未经验证的媒体连接自动放行。
- 支持的路径保持可用；无法满足约束的具体操作在建立不受控连接前给出提示。
- 不将直播分片播放和双向通话媒体混为一类；直播下载由条目 3 验证。
- 绑定变更、账号切换和代理故障不会把媒体转移到未绑定出口。

## 5. 内置网页及其他账号网络使用者隔离

**依赖**：2。

**交付**：内置网页及剩余账号网络功能使用明确的账号路由；不支持时展示限制说明，避免第三方页面静默直连。

**验收**：

- 区分通过 Telegram 获取的页面数据和网页引擎发出的请求，不误禁用前者。
- 原生网页引擎的存储隔离和网络隔离分别验证；覆盖页面导航、子资源、重定向及实际启用的其他连接类型。
- 覆盖目标平台的能力差异：没有完成隔离适配的平台不得展示虚假的可用状态。
- 不自动启动外部浏览器绕开限制。
- 完成账号网络使用者清单，对遗漏路径逐项接入或阻断；共享应用服务不能携带账号数据绕过约束。

## 6. 取消账号上限并实现头像快速切换

**依赖**：2。

**交付**：用户可以添加并恢复超过原有上限的账号，通过设计节点 `fXxHp` 的头像列快速切换，后台账号保持原绑定。

**验收**：

- 创建、保存、索引恢复、Premium 判断及全部切换入口不再施加原数量上限。
- 至少 7 个账号的保存恢复路径通过；删除和重新添加不会覆盖其他账号数据。
- 头像列包含当前账号、未读计数、添加和全部账号入口，大量账号可访问且不挤坏布局。
- 切换不修改代理，不重启无关账号连接；未读状态与对应账号一致。
- 以 500 条记录检查界面与数据结构，不把该结果当作 500 账号联网证明。

## 7. 账号管理、分组筛选与批量绑定

**依赖**：6。

**交付**：实现设计节点 `yZOtg` 范围内的账号管理，支持搜索、分组、状态筛选、分页和批量绑定。

**验收**：

- 搜索名称、手机号和标签，组合分组与状态筛选，并正确显示分页总数。
- 分组和标签可维护及恢复；删除分组不删除账号或代理绑定。
- 当前页选择与跨页全选含义明确；提交前固定目标集合，筛选变化不改变正在执行的操作。
- 批量绑定复用条目 2 的策略，提示共享出口；部分失败逐项反馈。
- 不新增账号凭据批量导入或批量修改资料等范围外能力。

## 8. 代理列表、批量导入与可取消检测

**依赖**：2。

**交付**：实现设计节点 `Ecw6D`、`Yfmf8` 的代理管理，向账号绑定入口提供可选代理。

**验收**：

- SOCKS5 与 MTProto 均可增删改；列表显示真实绑定数量、检测状态和实测延迟。
- 文本和剪贴板导入先预览，支持已确定格式、注释和 IPv6；错误项指出位置，不回显秘密。
- 未标注协议的简写按 SOCKS5 解析；MTProto 输入有明确协议及密钥，不能混淆。
- 检测受并发限制且可取消，实际业务连接与检测共用目标地址族设置；无法控制的 MTProto 服务端出口偏好不伪称已应用。
- 编辑、删除和清空先显示受影响账号；执行后绑定状态正确，旧检测结果不能污染新配置。
- 备注修改不重连；密码和密钥默认隐藏，未知国家信息不伪造。

## 9. 集成隔离验收与 500 账号容量验证

**依赖**：3、4、5、7、8。

**交付**：所有入口使用一致账号策略，完成协议组合、迁移、界面和容量验收；针对实测瓶颈进行必要优化。

**验收**：

- SOCKS5/SOCKS5、MTProto/MTProto、SOCKS5/MTProto 组合均覆盖切换、后台收信、传输与故障恢复。
- 通过代理端记录和进程网络观察验证正确出口，同时检查 DNS、直连及未绑定代理旁路。
- 取消剩余账号路径对全局可变代理的依赖；明确所有暂时受限功能，不能仅凭设置值或状态文案判定隔离成功。
- 对照四个设计节点检查布局，并完成针对改动的 Debug 构建与回归。
- 目标为 500 个真实账号持续联网 30 分钟，抽样收发、传输、切换及代理故障恢复；记录机器和负载、内存、线程、连接数与延迟。
- 已加载账号的本地界面切换 P95 目标不超过 500 毫秒；不计远端历史获取耗时。
- 模拟规模测试与真实联网验收分开报告。缺少专用账号或代理环境时，该项保持未完成，不使用日常账号或模拟结果替代。
