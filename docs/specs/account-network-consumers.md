# 账号网络使用者覆盖

条目 5 使用账号固定上下文。普通 HTTP 经 `MTP::HttpTransport`，WebSocket 经 `Core::WebSocketClient` 的账号构造函数。无账号的 WebSocket 构造保留为拒绝入口，不能发送网络请求。两种传输均只接受有效、当前代次、数字 IP 入口的 SOCKS5。

| 使用者 | 当前行为 | 撤销及限制 |
| --- | --- | --- |
| 原生 Instant View、网页文件、静态地图、网页元数据 | 保留账号 MTP 请求和本地渲染 | 普通 HTTP 下载由条目 3 处理 |
| 小程序、游戏、TON 网站、Markdown Embed、地图网页、支付和 3DS 网页 | 创建网页引擎前显示不支持账号隔离 | WKWebView、WebView2、WebKitGTK 均未开放；地图独立 NSURLSession/QNAM 桥接因此不可达 |
| 支付验证失败 | 保留错误页面 | 不再自动打开外部浏览器 |
| IV 无原生页面 | 显示网页隔离限制 | 不再自动回退到外部浏览器 |
| 外部网页账号登录 | 携带已批准网页登录上下文或客户端登录令牌时阻断交接 | 普通用户主动外链保持原行为，不宣称经过账号代理 |
| Stripe、SmartGlocal 卡片令牌 | 表单向库注入账号 HTTP manager | 撤销中止 reply；排队完成回调复查快照；MTProto 明确报错 |
| 自定义 URL 翻译 | 每次请求创建账号 HTTP manager | 撤销中止 reply，旧代次不交付成功结果 |
| Telegram 翻译、macOS 已安装语言包翻译 | 保留 MTP 或本地路径 | 未要求下载本地语言包 |
| 其他平台的外部翻译程序 | 显示系统服务隔离限制 | 不启动 Crow 等无法约束出口的进程 |
| 地址反查 | 每次请求使用账号 Mapbox HTTP manager | 不调用系统 geocoder；不共享账号网络池；15 秒请求超时 |
| 系统精确定位 | 显示限制并使用本地国家范围 | 不调用 CLGeocoder、Geolocator 或 GeoClue |
| 钱包 RPC、转账、TON Connect | 保留 MTP | 网页和 WebSocket 能力单独处理 |
| 钱包 WebSocket | 固定账号 SOCKS5，代理解析目标域名 | 撤销中止 socket 和重试计时器；可用新绑定重新订阅；不支持时提示，保留 MTP 周期同步 |
| Passkey 注册和登录 | 入口显示系统服务隔离限制 | 不启动未适配的系统认证或 caBLE；本地密钥的单独开放需要平台验证 |
| 支持模板远程刷新 | 使用账号 HTTP manager | 撤销清除 manager；异步解析结果复查快照；本地模板可用 |
| 代理推广信息 | 从当前账号快照生成代理标识 | 更换绑定取消旧请求、重新刷新 |
| 旧 WEB 代理 | 配置保留但不自动启动 carrier | 全局刷新只执行停用，不借迁移记录启动网页 |
| 应用更新 | 保留独立应用服务 | 更新请求携带应用版本和渠道，不取账号绑定 |
| 崩溃报告上传 | 显示限制，可保存本地报告 | 可能含账号数据，不经应用全局服务上传 |

## 已执行的验证

独立 `account_consumers` CTest 通过公开 WebSocket 接口和本机 TCP 观察端验证：无上下文不能直连；绑定 SOCKS5 接收到含目标域名的 CONNECT；撤销后代理端观察到 disconnected；进程全局的另一代理未接收到连接；有效 MTProto 绑定不能退化为普通 WebSocket 直连。

测试先在旧实现复现无上下文 WebSocket 直连，加入拒绝入口后通过。随后新增账号构造接口的代理观察测试，补齐代理注入和撤销后通过。该夹具直接完成账号路由验证，只证明 socket 路由及生命周期，不证明真实代理认证、TLS/WebSocket 服务或账号登录成功。

本轮使用 macOS 头文件对修改的生产翻译单元执行语法检查。受磁盘空间和授权构建范围限制，没有完整链接、真实账号操作、跨平台运行、网页网络进程观察或系统 DNS 抓包。网页零启动结论来自入口审查，仍需条目 9 通过实际 UI 和进程观测验收。500 账号联网验收不属于本记录的测试结果。
