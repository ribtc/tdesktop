# 多账号管理与账号网络隔离

本文件记录本次需求澄清。已确认范围可作为后续规格的输入；待决定项目不能视为用户已同意的行为。当前尚未实现或完成运行验证。

## 已确认范围

用户已确认以下三项建议：

1. 账号数量不设人为上限，以 500 个已登录账号同时联网为首轮容量验收目标。
2. 账号网络隔离从登录前开始，覆盖消息、文件、通话、内置网页及相关 DNS。未绑定、检测中和代理失效均阻断；不能保证经指定代理访问的功能暂时禁用并说明原因。不得静默直连或借用其他账号的代理。
3. 实现头像快速切换、账号搜索、分组、分页、批量绑定代理，以及代理增删改、文本和剪贴板导入、测速和地址族设置。账号凭据批量导入及批量修改资料另行定义，不在本次确认范围内。

“不设人为上限”不表示资源无上限。500 个同时联网账号是待验证目标，不能以 500 条静态列表数据或模拟登录身份替代真实联网容量结论。

## 现有实现约束

- `Main::Domain` 的账号创建和数量计算包含 3/6 个账号限制；`Storage::Domain` 在恢复时也限制账号数量和索引。必须同时处理创建、保存、恢复和切换入口。
- `Core::Settings::proxy()` 是全局代理设置。`Account::watchProxyChanges()` 监听全局变更，MTProto 实例和会话也读取全局代理。
- HTTP 文件下载使用共享网络管理器，不能仅靠账号 MTProto 设置推导其出口已经隔离。
- 代理域名解析和特殊配置请求存在显式直连代码，需要逐条消除或阻断不符合隔离约束的路径。
- 当前 `ProxyData::supportsCalls()` 返回 false。现有通话分支不能作为已具备代理隔离的证据。
- WebView 的独立存储配置不代表网络独立。现有 WEB 代理还使用进程级共享传输。

以上为静态代码调查，尚未通过各平台抓包或运行测试证明网络行为。

## 已确认的共享、迁移与协议范围

| 问题 | 决定 | 状态 |
| --- | --- | --- |
| 同一代理能否绑定多个账号 | 允许用户明确共享，提示可能共用公网出口 IP；账号连接和状态仍分开 | 已确认 |
| 已有账号如何升级 | 保留登录态和数据，将旧代理导入代理库；完成账号绑定前阻断，不自动给所有账号套用旧全局代理 | 已确认 |
| 首版代理兼容范围 | 必须支持 SOCKS5 和 MTProto | 已确认 |

首版入口地址继续以 IPv4/IPv6 字面地址作为规格草案默认值，避免引导解析走本机 DNS。HTTP、WEB 和域名配置保留，但不自动用于账号联网。此默认值与验收方法在规格终审时一并核对。

不得因代理类型为 MTProto 就一律禁用网页或音视频功能。网页文件可以通过 `upload.getWebFile` 获取，部分直播媒体通过 `upload.getFile` 和 `inputGroupCallStream` 下载；这些 MTProto 路径应纳入代理隔离支持和验证。任意网页的 WebView 请求、双向实时通话的 WebRTC 媒体连接需要分别核对实际出口。只有具体路径无法满足隔离要求时才阻断并提示，不能把通话信令成功当成媒体已走代理的证据。

此区分同时依据当前源码及官方[网页文件文档](https://core.telegram.org/api/files)、[群通话与直播文档](https://core.telegram.org/api/group-calls)、[通话连接文档](https://core.telegram.org/api/calls)。

可审阅的完整草案见 [功能规格](specs/account-network-isolation.md)。

## 验收方案草案

验收阈值、测试环境及最终执行范围仍需在规格中明确。

- 验证超过旧上限后的添加、保存、退出、重启、恢复和账号切换；不能截断账号列表或复用仍在使用的账号存储身份。
- 使用可区分的代理与目的端记录，检查不同账号的登录、消息和文件请求只经过其绑定代理。
- 在代理认证失败、断开、检测未完成、配置变更和删除等情形下验证阻断。检查已建立连接及延迟回调，不能只检查新的请求。
- 验证切换当前账号不会改变后台账号的网络出口；修改一个账号的绑定不应重启无关账号的连接。
- 检查 DNS、通话、WebView 及重定向等路径。受限制的功能必须明确提示，不得把禁用状态报告为已支持隔离联网。
- 以不同账号、分组、筛选、分页和批量选择组合验证操作目标。代理导入先预览，格式错误定位到具体输入，不能把错误数据静默修正为直连配置。
- 分别记录 500 条账号记录下的界面表现和 500 个账号同时联网的运行表现。记录硬件、构建配置、内存、线程、连接数、切换延迟和测试时长。
- 使用专用测试资料；缺少真实账号或代理测试环境时明确记录未验证项，不能操作日常账号替代容量测试。
